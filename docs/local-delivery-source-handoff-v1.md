# 本地演示交付与远程源码说明

本说明面向使用者和源码接手者。完整本地演示包与公开 Git 仓库用途不同，不应相互代替。

## 本地交付

本地材料提供原样运行源码、冻结前端、具名 S210 上下文/关系及两个候选样例、36 项已按官方 PyPI 大小/SHA 校验的依赖 wheel、安装启动说明和干净包校验工具。不包含旧虚拟环境、测试库、模型权重、密钥或完整历史运行目录。

使用者应先读包根目录的 `README.local-demo.md`，用明确选择的 Python 3.11 检查未初始化材料，再创建独立 `.venv` 并从 `dependencies/wheels` 离线安装。安装成功后，唯一推荐服务入口为：

```powershell
& ./.venv/Scripts/python.exe -B -X utf8 scripts/start_local_demo.py --workspace tmp/my_demo --check
& ./.venv/Scripts/python.exe -B -X utf8 scripts/start_local_demo.py --workspace tmp/my_demo
```

按终端实际输出的 127.0.0.1 地址，在新的隐私浏览器窗口打开；默认1800秒退出，Ctrl+C可停止。重启同一工作目录保留独立记录。不要清理具名冻结构建目录来“整理 tmp”，不要把演示记录回写原业务库。

## 能力与限制

当前交付默认离线，只开放已有页面与语义候选只读校验。F35400 保持限定消息触发判据/仅供审阅，F06000 保持整树阻断；不存在由本包批准的完整物理故障树。RAG、AI 抽取和正式建树等未启用路由明确拒绝，不自动调用云端模型。

本机的新目录/全新依赖环境、真实 HTTP、桌面/390 浏览器、停止重启已经验证。这不等于另一台机器验收、无限在线 RAG、真实设备概率或生产 FTA 已完成。新的在线模型调用仍须单独明确数据范围与预算。

SHA 是内容校验，不是数字签名、专家签署或素材许可。32 MiB 存储值是请求前后的检查阈值，不是系统硬配额；同账号恶意改文件不在本地宿主认证范围。日志中的固定 `provider_requests=0` 表示本离线配置的预期约束，不能当作独立计量仪器。禁用路由、空凭据、禁止外联及浏览器同源约束是不同层的证据。

## 公开源码边界

远程源码归档可包含打包/校验工具、必要业务源码、测试和去敏说明，但不代表完整本地资产获准公开。克隆源码不等于取得全部冻结资产，也不保证可直接执行需要本地身份账的 M3/M4 重放。缺少具名资料或指纹不一致时，应明确阻断；不得下载不明替代数据、改 SHA 或借用旧环境制造通过。

以下内容不随本次源码同步新增：完整本地包/ZIP、Gold/手册原文、图片和视频、模型/缓存、虚拟环境、数据库及原始模型/运行记录。既有仓库历史已经存在的媒体或数据不因此被追认许可；清理历史需要独立授权和方案，不擅自重写历史。

## 模块职责

| 目录 | 职责 |
| --- | --- |
| `backend-python/contracts` | 抽取、证据、审核、放行、语义计划的单一共享合同 |
| `backend-python/extraction` | 抽取/审核/持久化应用服务 |
| `backend-python/fta` | 因果/门型与来源边界校验、诊断投影及已有树路径 |
| `backend-python/rag` | 检索、关系展开、证据约束回答 |
| `backend-python/domains` | 领域适配和路由，不重写公共检索 |
| `backend-python/core` | 配置及模型客户端端口/基础工具 |
| `backend-python/app` | API 组合和协议接线，不私造业务真相 |
| `frontend/src` | 消费结构化状态，展示证据、候选与阻断 |
| `scripts` | 原安全启动和交付材料生成/校验工具 |
| `evaluation/quality_eval` | 本地观察/回归/审计，不拥有生产语义；部分输入仅本地保留 |

不为本次交付重排业务模块、不复制第二套后端，也不把“检索准确”或“候选能显示”改写成全量自动 FTA 放行。
