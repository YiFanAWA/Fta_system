## 历史评测

`evaluation/quality_eval/runs/` 中的 JSON 和图片来自 2026-03-31 的历史运行。本次只验证评测脚本能够编译并显示命令帮助，没有重新调用在线模型、Neo4j 或运行 API 模式评测，因此不能把这些数值描述为当前提交的结果。

## 前端工具链

生产依赖审计已无已知漏洞，但完整开发依赖树仍由旧版 Vue CLI 工具链带来 40 个审计项（3 low、19 moderate、16 high、2 critical）。`npm run build` 可以完成，不过仍会报告大媒体文件、入口体积和代码拆分建议。升级工具链属于后续独立任务，不能在目录迁移中用一次大版本升级混入行为变化。
